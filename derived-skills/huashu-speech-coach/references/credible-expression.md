# 可信表达补充（2026-10-22）

来源：[七个正在拖垮社交的不良习惯](https://mp.weixin.qq.com/s/xJprrGZRnHUSUlQeNzhiHA)。

用于修改演讲稿或排练口头表达时，按需检查：

1. 先说结论，随后给一条证据或具体场景，讲完停顿。
2. 删掉无信息量的自贬、重复解释与填充性对冲；保留真正的概率、条件、范围和未知。
3. 核心句放慢到能被听清，不固定要求降低20%。
4. 用“当时情境—变化—结果”解释价值，避免只列参数。
5. 用真实完成的工作展示能力；面对赞美可直接致谢。
6. 每周只练一个习惯，用录音与听众复述检查理解程度。

检查点：措辞更有力后，事实、证据与不确定性是否仍准确？未经核验的研究不能写成已证实定律。

原文没有给研究出处。该清单为情境性启发，不是对所有沟通环境有效的行为定律，不作为 Winston 原课内容。

# K-Fragment: 帧同步预测与回滚闭环
## A. Applicable — 适用场景
- 多端以输入驱动同一逻辑模拟，需要在网络时延下保持操作响应与最终一致性。
- 已能保存关键逻辑状态和历史输入，并能从旧状态确定性重放。
## B. Boundary — 边界与注意事项
- 没有确定性物理、随机数与跨平台数值策略时，输入相同也可能持续分歧。
- 状态同步或服务端权威模拟的回滚范围和校验机制不能照搬锁步模型。
- 输入延迟、回滚深度与视觉修正需在目标 RTT、抖动和 CPU 预算下实测。
## C. Core — 核心要点
1. 输入附逻辑帧序并保存历史；按帧获得权威输入。
2. 执行预测前保存关键世界快照，记录本帧采用的预测输入。
3. 权威输入到达后检测输入分歧，必要时再用状态校验识别同输入下的漂移。
4. 从最早有影响的快照恢复，用权威输入重放到当前帧。
5. 逻辑位置立即正确化，渲染位置按视觉规则独立平滑。
## D. Data — 关键数据与决策记录
- 原文以 RTT、等待窗口与固定延迟帧数说明取舍，未提供可通用复用的阈值。
- 项目至少记录每帧 RTT/抖动、预测命中率、回滚次数与深度、重放 CPU 耗时、状态哈希分歧数。

## A — Applicable

需要理解结构、参数敏感问题或随时间演化的抽象过程；单纯文字解释难以吸收时。

## B — Boundary

输出越复杂不等于理解越好，先核对公式与假设。公众号完整提示词是作者扩写，不是全部来自 Karpathy。ASD-STE100 的英文词数限制不直接用于中文；制作与校验成本并非零。

## C — Core

1. 流程与规范用简洁文字，术语保持一致。
2. 结构与层级用图，参数影响用交互网页，动态过程按需用视频。
3. 先写当前要理解的一个问题，再指定最小合适输出。
4. 一次性理解制品可以不产品化，但要用已知样例验证。
5. 无构建步骤不等于无网络依赖，检查单文件是否真能离线。

## D — Data

原文给出的作者补全提示词：

```text
Output as a single self-contained HTML file with Tailwind CSS and interactive JS sliders/animations, no build step.
```

中文替代（AI 补充）：请围绕这个问题生成单文件 HTML；内嵌样式和脚本，不依赖外部资源；列出假设，提供一个已知正确样例，只加入能帮助理解的最少交互。

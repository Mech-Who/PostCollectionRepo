## A · Applicable

适用于办公 AI、消费级 Agent 或内容产品设计 IP 联动，希望同时获得短期触达与长期留存时。

## B · Boundary

仅做主题皮肤和奖励容易在活动结束后流失；私有知识库还要有更新机制，否则时效性优势会迅速消失。

## C · Core

- 用 IP 视觉与任务奖励降低首次尝试门槛。
- 用场景专属 AI 专家解决公开搜索噪声和筛选成本。
- 将“情感吸引”和“持续功能价值”设计成互补层。
- 联动效果应分别观察拉新、任务完成和专家复用。

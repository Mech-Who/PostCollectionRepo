## A · Applicable

设计游戏编剧培养课程、叙事团队训练或实践型作业时，用能力目标对齐练习和评估。

## B · Boundary

五个领域是访谈归纳的教学框架，不是通用的岗位招聘标准；不能用一次性交稿代替迭代与协作，也不能只凭课堂参与感判断学习成果。

## C · Core

- 明确写作与叙事、沟通与协作、游戏系统与动力、工具熟练度、玩家理解五个能力领域。
- 为文字匠人、感悟者、倡导者安排不同任务，练习角色转换。
- 以短期作品、改稿、工作坊、团队重组和反思提供可观察证据。
- 在有限课时下，使目标、教学活动与效果评估形成闭环。

## D · Data

```text
能力目标 -> 实践作业 -> 反馈与迭代 -> 可观察的学习成果
```

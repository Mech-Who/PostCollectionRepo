跑团改编与裁决叙事分离

A — Applicable

把跑团日志改为公开故事、视频或受限游戏，或评估 AI DM 设计。

B — Boundary

玩家与观众需求不同；有限分支不承诺无限自由。本文没有 AI DM 基准测量；裁决与叙事分离是基于风险提出的工程建议，未经本案例验证。

C — Core

  1. 提取观众能理解的冲突、人物目标和因果链，避免照搬内部梗。
  2. 即兴表演与视听改编是两类内容价值。
  3. 排期与长期稳定参与比纸笔成本更可能成为跑团门槛。
  4. 状态记忆、规则与随机骰子不能由顺畅叙事替代。
  5. 工程上可考虑外部状态和确定性裁决，AI 负责解释与叙述，明确未支持动作（AI 补充）。

D — Data

评估记录（AI 补充）：角色状态｜已揭示线索｜规则版本｜真实骰子结果｜裁决依据｜叙事输出｜玩家异议。

没有具体规则实现与 API 契约，不生成看似可运行但未经验证的 DM 代码。

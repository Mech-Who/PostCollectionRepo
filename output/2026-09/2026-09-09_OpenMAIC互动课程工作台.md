> **摘要：** 清华团队开源的 OpenMAIC 已从多智能体互动课堂生成器升级为课程创作者的专业工作台。它把课程规划、页面制作、互动实验、旧 PPT 改造和个人教学风格复用组织成可持续迭代的 Agent 工作流，并用 20 多个教学 Skill 将费曼学习、螺旋式课程等方法显式封装。

## 我的理解
> 由小林生成，供小涵审阅修改

OpenMAIC 有价值的地方不只是“一句话生成课件”，而是把课程制作从一次性生成改造成可反复沟通、规划、逐页修改和复用的工作台。教师仍掌握课程目标与判断，Agent 负责展开素材、页面和互动形式。

教学 Skill 是整个产品的关键抽象。费曼学习、螺旋式课程、项目式学习和个人授课习惯被封装成可组合的生成约束，使同一份材料能够得到结构明显不同的课程。这比只更换提示词更容易复用、分享和持续修正。

另一个务实之处是尊重已有资产。旧 PPT 不必废弃，可以保留页面和排版，让 Agent 补上讲解、聚光、语音、测验和互动；需要时再做深度重构。它降低了教师采用新工具的迁移成本。

## 关键要点

- **工作台化**：教师持续与 Agent 沟通，规划连续课程、整理材料、生成页面并逐页修改，而不是接受一次性结果。
- **互动表达**：可生成三维可视化、模拟实验、知识游戏、思维导图和在线编程页面，把抽象知识转成可操作对象。
- **Skill 驱动**：20 多个内置教学 Skill 改变课程结构，教师也能从自己的课程记录中创建个人 Skill。
- **旧资产增强**：导入 PPTX 后尽量保留排版，再补充讲解、语音、提示、测验与互动页面。
- **风格提取**：可从授权课堂录像或讲义中分析开场、举例、节奏和复盘习惯，用于生成新课程。
- **开放部署**：支持云端模型 API、本地 Ollama 或 Lemonade，并可部署到 Vercel、Docker 或自有服务器。

## 原文整理

OpenMAIC 全称 Open Multi-Agent Interactive Classroom，由清华大学团队开源。项目最初定位为多 AI Agent 互动课堂生成器，现已升级为面向课程创作者的专业工作台。项目在 2026 年 3 月开源，文章发布时已获 3 万多个 GitHub Star，并受邀在联合国教科文组织巴黎总部展示 AI 教育智能体。

### 从主题生成互动课堂

用户输入主题或上传学习材料后，系统可以生成幻灯片、测验、互动实验和项目式学习任务。课堂中设置 AI 老师、助教和同学角色，可进行讲解、提问、讨论、白板绘图和公式推导。

深度交互模式能够生成三维可视化、模拟实验、知识游戏、思维导图和在线编程页面。例如物理课程可以让学生调整参数并观察模拟结果，课程不再只是文字和静态图片的排列。

### 用 Skill 固化教学方法

工作台内置 20 多个教学 Skill。费曼学习法会先让学生解释概念，再通过追问寻找并补全理解缺口；螺旋式课程让核心概念在多次课程中重复出现，并逐步增加情境和难度；大师讲授 Skill 则强调连续讲授主线、较高信息密度和真实案例。

教师还能把自己的教学流程整理为个人 Skill，供后续课程复用。由此，教学法从隐含在提示词或个人经验中的习惯，转化为可以选择、组合和改进的工作单元。

### 让旧课件继续产生价值

OpenMAIC 支持导入 PPTX，并尽量保留原页面与排版。教师可以逐页补充讲解、聚光提示、语音、测验和互动页面，也可以把整套课件作为素材重构成深度互动课堂。

系统还可以在获得授权的前提下分析课堂录像或讲义中的开场方式、举例顺序、讲解节奏、复盘方式，以及语言和画面的配合，再用这些风格特征生成新课程。

### 部署方式

本地运行需要 Node.js 22.19.0 以上和 pnpm 10.28.0。克隆仓库并安装依赖后，复制环境变量示例并配置模型服务，再运行开发服务器。系统可接云端 API，也支持本地 Ollama 或 Lemonade；长期运行可构建生产版本，并部署到 Vercel、Docker 或自有服务器。语音、图像和文档解析功能需要额外配置。

开源地址：https://github.com/THU-MAIC/OpenMAIC
